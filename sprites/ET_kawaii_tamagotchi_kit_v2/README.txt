ET GAME SPRITE KIT - EQUALIZED

Tous les fichiers sont en PNG transparent avec une taille uniforme de 512x512 px.

Dossiers :
- baby_states        : états principaux du bébé
- baby_actions       : animations / actions du bébé
- icons              : icônes et FX
- teen               : version ado
- adult              : version adulte
- elder              : version vieux
- evolved_stage_1    : évolution supérieure 1
- evolved_stage_2    : évolution supérieure 2
- special            : sprites spéciaux

Conseil code :
- Utiliser le nom de fichier comme clé d'état
- Les préfixes numériques conservent l'ordre logique
- Voir manifest.json pour un index complet
